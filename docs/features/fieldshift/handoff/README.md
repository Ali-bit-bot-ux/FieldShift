# Какую версию скачать

Для работы всей команды скачайте **полный репозиторий из main** и следуйте [инструкции запуска](../../../../README.md). Он включает Next.js, FastAPI, агродвижок и кеш NASA. Общая команда запуска после установки зависимостей — `python scripts/run_fieldshift.py`.

В этой папке сохранён первоначальный комплект для передачи самостоятельного фронтенда. ZIP запускает четырёхлетний демонстрационный пример. Для подключения этого комплекта к объединённому сервису задайте `FIELDSHIFT_DATA_MODE=api` и `FIELDSHIFT_API_URL=http://127.0.0.1:8000/api/recommendation` в web/.env.local. В документе Word адрес Python был приведён как пример до объединения веток.
