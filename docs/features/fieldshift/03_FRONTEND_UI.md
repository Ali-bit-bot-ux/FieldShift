## 🎯 Твоя задача:
Сверстать яркий, интуитивный интерфейс инструмента **FieldShift: Crop Rotation Planner**.  
С первой же секунды ты работаешь на **встроенном fixture-ответе из `00_CONTRACT.md`** (это только UI-заглушка для верстки, не production-данные) и никого не ждешь. После интеграции fixture заменяется вызовом `get_fieldshift_recommendation()`; в финальном UI мок-данных быть не должно.

### 1. Файлы, с которыми ты работаешь:
* ✏️ `dashboard/rotation_planner_tab.py` — отдельный изолированный файл вкладки севооборота.
* ✏️ `dashboard/app.py` — ТОЛЬКО регистрация вкладки (1 строка вызова `render_rotation_planner_tab()`, запрещено раздувать `app.py`!).
* 🚫 **ЗАПРЕЩЕНО трогать:** `pipeline/gee_client.py`, `modules/m6_rotation_planner.py`.

## 📋 Чек-лист шагов:

- [ ] **Шаг 1. Панель параметров фермера (Сайдбар или верхний блок):**
  - Выбор области: СКО, Костанай, Акмола, Павлодар.
  - Выбор типа почвы (подгружать список из `dataset/soils.json`).
  - Площадь поля (га).
  - **4 слайдера весов (Приоритеты фермера):**
    * `🌾 Доход от урожая`
    * `💧 Экономия поливной влаги`
    * `🌱 Восстановление здоровья почвы`
    * `💰 Минимизация затрат на семена/ГСМ`
- [ ] **Шаг 2. Карточки 3 стратегий ротации (Презентационный вау-эффект):**
  - Сверстать 3 карточки в ряд (Streamlit columns):
    1. 🟢 **«Сбалансированная (Рекомендация NASA FieldShift)»**
    2. 🔵 **«Максимум восстановления почвы (Soil Resilience)»**
    3. 🔴 **«Традиционная монокультура (Высокий климатический риск)»**
  - В карточке отобразить: итоговый скор, % сэкономленной воды, прирост здоровья почвы.
- [ ] **Шаг 3. Интерактивные графики Plotly (4-летняя динамика):**

  - **График 2:** Индекс здоровья почвы (Soil Health Score) по годам: наглядно показать, как на традиционной монокультуре линия падает вниз (деградация), а на рекомендации NASA — растет вверх.
- [ ] **Шаг 4. Блок объяснения решений (Explainable AI):**
  - По каждому году вывести понятное обоснование: *«Почему именно эта культура?»* (на двух языках: KK/RU).
