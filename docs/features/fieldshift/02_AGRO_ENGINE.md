## 📋 Чек-лист шагов:

- [ ] **Шаг 1. Матрица агро-правил (`dataset/rotation_rules.json`):**
  - Зашить научные правила чередования:
    * *Пшеница после пшеницы:* допустимо не более 2 лет подряд (риск корневых гнилей).
    * *Бобовые (нут, чечевица, горох):* лучший предшественник для яровых злаков (+25–35 кг/га азота, экономия воды 30%).
    * *Подсолнечник:* перерыв возврата на то же поле минимум 4 года (истощает почву на глубину 2+ м).
    * *Лен масличный:* перерыв возврата минимум 3 года.
- [ ] **Шаг 2. Формула Soil-Health Score ($SHS \in [0, 100]$):**
  - Базовое состояние почвы берется из `dataset/soils.json`.
  - Динамика по годам ротации:
    $$SHS_{t} = SHS_{t-1} + \Delta_{\text{бобовые}} (+12) - \Delta_{\text{истощение}} (-8) + \Delta_{\text{NoTill}} (+5)$$
  - Учет засоления и коркообразования: если почва склонна к корке (солонцы), бонус дается культурам со стержневым корнем.
- [ ] **Шаг 3. Оптимизатор ротации по весам фермера:**
  - Целевая функция выбора лучшей цепочки:
    $$\text{Score} = w_1 \cdot \text{Yield} + w_2 \cdot \text{WaterSaving} + w_3 \cdot \Delta SHS - w_4 \cdot \text{Cost}$$
  - Сгенерировать 3 контрастные стратегии:
    1. *«Сбалансированная (Рекомендуемая NASA)»*
    2. *«Максимум восстановления почвы (Soil Saver)»*
    3. *«Традиционная (Монокультура с высокими рисками)»*
- [ ] **Шаг 4. Сборка функции планировщика:**
  - Предоставить класс `CropRotationEngine`:
    ```python
    engine = CropRotationEngine()
    result = engine.generate_strategies(soil_id, region, priorities, climate_data)
    ```

  - `soil_id` — это `payload["soil_type"]`; не придумывать отдельные ID.
  - `result["strategies"]` обязан содержать ровно три стратегии с `strategy_id`:
    `recommended`, `soil_resilience`, `traditional_risk`.
