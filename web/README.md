# FieldShift · планировщик севооборота

Приложение для одного поля с русским, казахским и английским интерфейсом. Параметры поля, приоритеты, выбранная стратегия и последний успешный ответ сохраняются в браузере. Данные справочников и четырёхлетний демонстрационный ответ берутся из родительского проекта при сборке. Оставьте папку `web` внутри FieldShift.

## Локальный запуск

Проверено с Node.js 24 и npm. Выполните из каталога `web`:

```sh
npm ci
npm run dev
```

Откройте [FieldShift](http://localhost:3001). По умолчанию используется `fixture`. Интернет нужен для установки пакетов. После установки графики, шрифт, иллюстрация, справочники и пример загружаются локально. Ссылки на документацию NASA в панели помощи открывают внешние сайты.

Для прогона перед защитой остановите dev-сервер и используйте production-сборку:

```sh
npm run build
npm start
```

Оба варианта запуска привязаны к loopback на порту 3001. Для сборки используется поддерживаемая опция Next.js `--webpack`. Она позволяет собрать Tailwind в этой среде, где служебный порт Turbopack ограничен.

## Сценарий показа

1. Выберите область, почву и площадь. Паспорт поля справа сразу отразит изменения. На телефоне он находится под формой.
2. В приоритетах выберите пресет или переместите ползунки. Четыре нуля дадут равные веса.
3. Нажмите «Посмотреть пример». Выберите одну из трёх стратегий и откройте её последовательность культур. На вкладке графиков доступны потребность в воде, исторический ориентир IMERG, индексы почвы и таблица.
4. Переключите язык и распечатайте выбранную стратегию. Браузер позволяет сохранить PDF. Печатная форма использует компактные диаграммы выбранного плана и включает все годы, объяснения, параметры и режим данных.

В деморежиме показатели одинаковы для любых настроек. Трёхлетний горизонт открывается в режиме API. Смена режима исключает восстановление результата из другого режима.

## Инструменты хозяйства

Пункт «Инструменты хозяйства» открывает семь разделов. Ссылка с нужным разделом открывается напрямую.

| Раздел | Действие |
| --- | --- |
| [PhenoMap](http://localhost:3001/#phenomap) | Сравнить индекс растительности в четырёх точках со значениями прошлых лет. |
| [HydroRisk](http://localhost:3001/#hydrorisk) | Посмотреть сезонную влажность и величину отклонения в каждом районе. |
| [Backtesting 2021](http://localhost:3001/#backtesting) | Выбрать порог и найти первую дату сигнала в архивном ряду. |
| [SiloGrid](http://localhost:3001/#silogrid) | Ввести параметры элеваторов, проверить вместимость, маршрут и стоимость перевозки партии. |
| [Contagion](http://localhost:3001/#contagion) | Изменить условия хозяйства и проследить влияние дефицита воды на объём зерна и выручку. |
| [Vulnerability](http://localhost:3001/#vulnerability) | Сравнить четыре района по влажности, состоянию растений и сценарию доступности элеваторов. |
| [AgroAdvisor](http://localhost:3001/#agroadvisor) | Подобрать действия на 48 часов, сезон и следующие годы по культуре, почве и фазе развития. |

Планировщик, архивные измерения и пользовательские сценарии работают независимо. Периоды, координаты, методика и лицензия границ приведены в [источниках данных](data/SOURCES.md).

## Подключение Python-сервиса

Интегратору нужно реализовать HTTP POST к рабочему Python-фасаду. В исходном архиве фасад возвращает демонстрационный JSON. Для персонального расчёта потребуются климатические данные и агрономический движок.

1. Скопируйте `.env.example` в `.env.local`.
2. Задайте `FIELDSHIFT_DATA_MODE=api` и `FIELDSHIFT_API_URL` с полным адресом Python-обработчика, включая путь.
3. Перезапустите Next.js. Браузер обращается только к `POST /api/fieldshift/recommendation`.

Запрос и успешное тело ответа описаны в [контракте команды](../docs/features/fieldshift/00_CONTRACT.md). Веса отправляются в диапазоне 0–1, сумма равна единице. Клиент проверяет ID, числа, годы, уникальность стратегий и схему климатических полей. Серверный адрес остаётся на стороне Next.js. Таймаут upstream — 20 секунд. Ошибка сервиса переводит экран в состояние повторной попытки с последним успешным планом.

Для англоязычных объяснений новых комбинаций передавайте в каждом году необязательные `rationale_en` и `crop_name_en`. Для примера переводы встроены. Если старый API пришлёт незнакомое обоснование только на RU/KK, интерфейс предложит открыть оригинал на одном из этих языков.

После первого запроса редактирование формы запускает пересчёт через 600 мс. При печати старого расчёта используются параметры его снимка. Ключ хранения — `fieldshift.planner.v1`.

## Проверки

```sh
npm run typecheck
npm run lint
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

На машине с установленным Google Chrome можно выполнить `PW_CHANNEL=chrome npm run test:e2e`. Браузерным тестам нужны свободный порт 3002 и production-сборка. На 3001 тесты запускают сервер или используют запущенный экземпляр в режиме fixture. Дополнительный сервер на 3002 используется для проверки поведения UI в API-режиме на контролируемом HTTP-ответе. Чтобы сохранить скриншоты и PDF, задайте `FIELDSHIFT_QA_DIR`.
