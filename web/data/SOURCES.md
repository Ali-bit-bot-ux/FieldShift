# Архив для инструментов хозяйства

В `observations.json` четыре точки с координатами в WGS84. Тайынша — 53,84° с. ш., 69,78° в. д., Фёдоровка — 53,63°, 62,85°, Есиль — 51,95°, 66,43°, Теренколь — 53,05°, 76,13°. Контуры районов дают географический контекст. Значение относится к спутниковой ячейке у точки.

- **Растительность.** Для MOD13Q1 выбран пиксель в точке (250 м), канал `250m_16_days_NDVI`, дни года 145–241 с шагом 16. Для каждого года 2018–2021 запросите `/api/v1/MOD13Q1/subset` с `latitude`, `longitude`, `kmAboveBelow=0`, `kmLeftRight=0`, `startDate=A{year}145`, `endDate=A{year}241` и нужным `band`. Сохранены значения от −2000 до 10000 при `250m_16_days_pixel_reliability=0` и умножены на масштаб 0,0001. [Сервис NASA ORNL DAAC](https://modis.ornl.gov/data/modis_webservice.html) · [Цитирование сервиса](https://doi.org/10.3334/ORNLDAAC/1600).
- **Влажность.** Из ежедневного архива NASA POWER SMAP L4 взят `SFMC`, объёмная влажность верхних 5 см, м³/м³. Выбраны ближайшие к точке широта и долгота сетки, сохранённые в `gridLat` и `gridLon`. Для дней года 145–257 извлечены отсчёты 2018–2021 годов. После декодирования значений Zarr оставлен диапазон 0–0,9. [Методика NASA POWER](https://power.larc.nasa.gov/docs/methodology/data/sources_hydrology/) · [Метаданные архива Zarr](https://nasa-power-smap.s3.amazonaws.com/smap/temporal/power_smap_daily_temporal_utc.zarr/.zmetadata).
- **Сравнение.** Для каждого дня сезона 2021 ориентир — среднее для того же номера дня в 2018, 2019 и 2020 годах при наличии хотя бы двух значений. Пропуски сохранены как `null`. Процент дефицита за период равен `100 × (1 − сумма наблюдений / сумма значений ориентира)` по сопоставимым датам. Порог в Backtesting выбирает пользователь. Дата сигнала — первая дата ниже порога в видимом интервале. Это ретроспективная проверка порога для одной точки.
- **Границы.** Файл `district-paths.json` производен от KAZ-ADM2-9891525, границы за 2017 год. Для карты выбраны и перепроецированы контуры в пределах северного зернового пояса. © OpenStreetMap contributors, Wambacher, через geoBoundaries. Производный набор границ распространяется по ODbL 1.0. [Исходная геометрия](https://github.com/wmgeolab/geoBoundaries/raw/9469f09/releaseData/gbOpen/KAZ/ADM2/geoBoundaries-KAZ-ADM2_simplified.geojson) · [Лицензия](https://opendatacommons.org/licenses/odbl/1-0/).
- **Агрономические советы.** `advice.json` содержит фазы культур, меры и подходящие пары почв и культур из справочников проекта. Английские названия переведены для интерфейса. [Справочники команды](../../dataset).
- **Логистика и экономика.** Начальные площадки A и B, дорожные расстояния, загрузка, тарифы и коэффициенты потерь — редактируемые условия примера. SiloGrid хранит площадки на этом устройстве. Contagion рассчитывает последствия введённых допущений. Для Vulnerability доступность хранения берётся из текущего сценария SiloGrid. Этот индекс не проходил полевой валидации.
